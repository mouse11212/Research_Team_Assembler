## 1. 背景与问题

2026-06-27 改进版 W2S01 接入主线后跑 0629 预测,暴露**综合分仍同质(Top5 挤在 54–57)**。根因诊断:

- **W2S02(量价)**`w2s_daily_factors.py:254-279`:二值"昨弱"门槛 + `ratio_score`(放量,封顶50)+`pct_score`(涨幅×5,封顶50)加性结构。活跃池票今日普遍涨≥5%+放量+昨日恰弱 → 普遍 90–100。**且完全不看 K 线形状**(放量长上影 vs 放量光头阳同分)。
- **W2S03(技术)**`w2s_daily_factors.py:300-335`:纯二值突破累加(破5/10/20日线 + 多均线 + 涨幅>3%),大涨票一天穿光所有均线 → 顶格 100。**无突破"幅度"刻度**。
- W2S04/05/06:依赖缺失数据(flow/NLP/细分行业),已正确走 None,**不在本轮范围**(属计划3 数据补全)。

**病理共性**:满分泛滥 + 与已乘性化的 W2S01 高相关(都吃涨幅/量比/均线)→ 三因子等于"三票投同一人",综合分无区分度。

## 2. 设计目标

1. **根治满分泛滥**:连续乘性打分,消除二值门槛与加性双满分项的悬崖。
2. **去冗余**:重定义 W2S02/03 语义,使三个 W2S 本地因子信息正交。
3. **非破坏**:签名不变,新字段缺失回落旧逻辑;调用方零改动。
4. **可回测**:全阈值配置化,初值经验给定,留调优。

## 3. 因子分工(重定义后,信息正交)

| 因子 | 维度 | 回答的问题 |
|------|------|-----------|
| W2S01(已完成) | 时间·拐点形态 | 过去几日健康回调 + 今日放量转强? |

一只票 W2S 拿高分需三维同时成立 → 综合分自然拉开区分度。

## 4. W2S02 设计:当日量价配合质量

立意:与 W2S01 的"量比"去冗余——W2S01 关心放量多少,W2S02 只关心**放量有没有被价格走势确认**。

```
W2S02 = 100 × vol_burst × price_confirm

  vol_burst     = 量能爆发度(门控):今量 / 窗口均量,clamp((vr - 1) / VR_SPAN, 0, 1)
                  VR_SPAN 默认 1.5(即量比 2.5 倍封顶)
  price_confirm = w_body · body + w_pos · closepos      默认 w=(0.5, 0.5)
     body    = 实体多头度:clamp((close - open) / open / BODY_SPAN, 0, 1)   BODY_SPAN=0.05;收阴→0
     closepos= 收盘强势度:(close - low) / (high - low)                     收最高→1、最低→0
```

**边界守卫**:`high == low`(一字涨停/跌停板,全天无振幅)→ closepos = 1.0(封板=最强势,不除零)。`open <= 0` 防御性返回 body = 0。

**乘性意义**:放量但收阴或收长上影(price_confirm≈0)→ W2S02≈0,即"光放量不算数,价格形态须站住"。
**Fail-Loud**:open/high/low/close/volume 任一缺失致整侧不可算 → 返 None;窗口均量不可得 → vol_burst 维降级(此处 vol_burst 是门控因子,缺失则整体不可算返 None)。

## 5. W2S03 设计:均线趋势结构

立意:砍掉旧版"昨下今上(刚突破)"语义(与 W2S01 拐点重复),专测**均线是否已是健康多头结构**(趋势状态,非拐点事件)。

```
W2S03 = 100 × trend_align × ma_position

  trend_align = mean( clamp((ma5 - ma10) / ma10 / S, 0, 1),
                      clamp((ma10 - ma20) / ma20 / S, 0, 1) )   S=0.02
                完美多头发散→1;纠缠→~0.5;倒挂(空头)→0
  ma_position = 0.5·clamp((close-ma5)/ma5 /P, 0,1)
              + 0.3·clamp((close-ma10)/ma10 /P, 0,1)
              + 0.2·clamp((close-ma20)/ma20 /P, 0,1)            P=0.03
                站稳三线→1;跌破→0
```

**Fail-Loud**:某均线缺失(0/None)→该子项剔除、同侧重归一化;ma5/ma10/ma20 全缺 → 返 None。
