# 弱转强准入门槛设计 — W2S01≥gate 提升为活跃池硬门槛

> **日期**: 2026-06-28 ｜ **承接**: spec `11_活跃池优化与弱转强重构设计`(计划3 的弱转强门槛部分);W2S01/02/03 乘性化已合入 main。
> **状态**: 设计定稿,待 writing-plans 拆 task 实现。

---

## 1. 背景与问题

W2S01/02/03 乘性化后,0626 选出的 Top5(605366/002668/603977/600520/002225)经逐只弱转强分项拆解,**没有一只是真弱转强买点**:
- 605366(W2S01=28.4)/600520(32.3):过去5日回撤=0%,持续暴涨/高位横盘到新高,**根本没"先弱"**。
- 002668(38.1):回撤仅2.1%(<3%健康下限)且回调期放量(非缩量洗盘)。
- 603977(62.1)/002225(63.5):相对接近,但 002225 今日放量不足(量比1.67)。

**根因**:弱转强(W2S01)在综合分里只占 ~8% 权重,被 W2S02 量价 + W2S03 均线(强势票上都接近满分)主导。改进版 W2S01 **准确识别**了这些不是弱转强(打了低分),但作为**加权因子无力否决**。

## 2. 目标

把弱转强从"下游加权因子"提升为**活跃池准入硬门槛**:`W2S01 ≥ gate` 成为与"今日涨幅≥5%"并列的准入条件(AND)。使进入综合分排序的每一只候选都**先通过弱转强检验**,选出的 Top 是"真弱转强龙头"而非"放量突破强势票"。

## 3. 设计

### 3.1 接入点
在 `data_fetcher_v3_integrated.py` 的 `_filter_active_from_kline`:`candidates = df[df['change_pct'] >= min_change_pct]`(455 行)**之后**、`_rank_by_leader_strength`(458)**之前**插入门槛过滤。准入逻辑内聚在活跃池构建一处(不放 main.py 绕过封装,不塞 `_rank` 混淆准入与排序)。

### 3.2 核心方法 `_filter_by_w2s01_gate`
完全仿照已验证的 `_compute_volume_ratio`(480-501)逐票取历史范式:

```
def _filter_by_w2s01_gate(self, candidates, trade_date, gate) -> DataFrame:
    对每个候选 code:
      DB 查 SELECT close_price,volume,ma20,ma5,change_pct FROM stock_kline
              WHERE stock_code=? AND trade_date<=? ORDER BY trade_date DESC LIMIT L+1
      若行数 < L+1 → 剔除(窗口不足)
      rows 反转为升序;today=rows[-1];window=rows[:-1] 映射 {close/volume/ma20}
      td = {change_pct/volume/close/ma5/window_klines}
      w2s01 = self._w2s_calc.calculate_W2S01(td, {})
      保留当且仅当 w2s01 is not None and w2s01 >= gate
    返回保留 code 的 candidates 子集(保序)
```

### 3.3 数据流
`get_active_stocks → [涨幅≥5%] → [W2S01≥gate 门槛] → 三维龙头强度排序 → top_n`

### 3.4 复用 calculate_W2S01
门槛调用 `DailyW2SFactors.calculate_W2S01`(已合入 main 的改进版乘性逻辑)。准入判据与下游因子分用**同一套弱转强定义**,杜绝"准入说是弱转强、因子分说不是"的自相矛盾。`__init__` 实例化一个 `self._w2s_calc = DailyW2SFactors()`(无循环 import:DailyW2SFactors 不依赖 data_fetcher)。

## 4. gate 与配置

- **gate 初值 = 50**(配置化,留回测调优)。依据 0626 活跃池实测分布(见 §8):W2S01 中位37.8/P75=50.5,gate=50 保留 46只(26%),挡掉今日 605366/600520/002668(W2S01<50),放行 603977/002225。
- 经 `__init__` 读取:`self.w2s01_gate = float(os.environ.get('QSS_W2S01_GATE', config.get('w2s01_gate', 50)))`(仿现有 `QSS_LEADER_W_*` 惯例)。

## 5. Fail-Loud 与边界

- **窗口不足(<L+1 日)→ 剔除**:弱转强语义需前期回调历史,次新股无历史=非弱转强标的;与 gate=50 严格一致。
- **单票 DB 查询失败/异常 → 剔除该票**(保守,不放行未检验票)。
- **整库连接失败 → 跳过门槛 + 警告日志**(避免门槛 bug 致全空)。
- **门槛后候选为空**(极端无弱转强行情)→ 候选池空 → daily 空仓,与系统"宁可错过不可做错"一致;`log` 明示"弱转强门槛后无候选"。

## 6. 验证

1. **集成测试(真实 DB)**:0626 活跃池过门槛后,605366/600520/002668 被剔除、603977/002225 保留;断言保留票的 W2S01 均 ≥50。
2. **daily 端到端**:`cli.py --date 20260626 --mode daily` 跑通,新 Top5 每只 W2S01≥50(读报告 W2S01 列核对)。
3. **回测**:`_s1_verify 20260101 20260331` 北极星 trades>0 不回归;记录交易数/盈亏比变化(门槛收紧候选池,预期交易数下降、弱转强纯度上升)。
