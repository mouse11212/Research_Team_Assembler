# 扎根理论方法论

## 概述

扎根理论（Grounded Theory）是一种从数据中归纳理论的质性研究方法，由Glaser和Strauss于1967年提出。它强调通过系统化的数据收集和分析过程，让理论从数据中"涌现"出来，而非验证已有假设。扎根理论特别适用于探索性研究和现象理解，帮助研究者在缺乏成熟理论的领域构建新理论。

**核心理念**：理论应该从数据中产生（emerge），而不是被强加于数据之上。

## 核心概念

### 基本定义

**扎根理论**：一种通过系统化的数据收集和分析，从数据中发展理论的归纳性研究方法。

### 核心特征

| 特征 | 描述 |
|------|------|
| 归纳性 | 从具体数据归纳出抽象概念 |
| 涌现性 | 理论从数据中自然涌现 |
| 比较性 | 持续比较是核心分析策略 |
| 理论抽样 | 根据理论需要决定抽样方向 |
| 饱和性 | 数据收集直到不再出现新概念 |

### 主要流派

| 流派 | 代表人物 | 特点 |
|------|---------|------|
| 经典扎根理论 | Glaser & Strauss | 强调理论的涌现，研究者开放性 |
| Strauss学派 | Strauss & Corbin | 强调编码的系统性程序 |
| 建构主义扎根理论 | Charmaz | 强调研究者的主动建构角色 |

## 方法论步骤

### 阶段1：研究问题界定

**目标**：明确研究焦点但不预设假设

**步骤**：
1. 确定研究兴趣领域
2. 形成开放的研究问题
3. 避免预设理论框架
4. 保持理论敏感性

**输出**：
- 研究问题陈述
- 研究兴趣说明
- 初步文献回顾（避免过度）
- 理论敏感性笔记

**质量检查**：
- [ ] 研究问题开放且聚焦
- [ ] 未带有预设假设
- [ ] 保持理论敏感性
- [ ] 文献回顾适度

### 阶段2：初始数据收集

**目标**：开始收集和分析数据

**步骤**：
1. 选择初始抽样策略
2. 收集多元类型数据（访谈、观察、文档等）
3. 同步开始数据分析
4. 记录研究备忘录

**输出**：
- 原始数据（访谈转录、观察笔记等）
- 初始编码
- 研究备忘录
- 方法论笔记

**质量检查**：
- [ ] 数据来源多元
- [ ] 数据收集与分析同步
- [ ] 备忘录记录及时
- [ ] 保持开放态度

### 阶段3：开放编码（Open Coding）

**目标**：将数据分解并命名概念

**步骤**：
1. 逐行/逐句分析数据
2. 识别有意义的单位
3. 为每个单位命名（编码）
4. 比较编码之间的相似和差异
5. 将相似编码归类为概念

**输出**：
- 开放编码列表
- 概念分类
- 编码备忘录
- 概念定义

**质量检查**：
- [ ] 编码贴近数据
- [ ] 编码命名准确
- [ ] 概念归类合理
- [ ] 持续比较分析

### 阶段4：轴心编码（Axial Coding）

**目标**：建立概念之间的关系

**步骤**：
1. 识别核心类别
2. 分析类别之间的关系
3. 明确因果条件、现象、背景、干预条件、行动策略和结果
4. 发展类别的属性和维度

**输出**：
- 核心类别识别
- 类别关系图
- 轴心编码范式
- 关系备忘录

**质量检查**：
- [ ] 核心类别明确
- [ ] 关系有数据支撑
- [ ] 范式要素完整
- [ ] 属性维度丰富

### 阶段5：选择性编码（Selective Coding）

**目标**：整合和发展核心理论

**步骤**：
1. 确定核心类别
2. 系统化核心类别与其他类别的关系
3. 补充需要发展的类别
4. 整合形成理论框架
5. 撰写理论陈述

**输出**：
- 核心理论框架
- 理论陈述
- 整合图示
- 理论备忘录

**质量检查**：
- [ ] 核心类别统领全局
- [ ] 理论框架完整
- [ ] 关系整合清晰
- [ ] 理论陈述准确

### 阶段6：理论饱和与验证

**目标**：确认理论的充分性

**步骤**：
1. 继续理论抽样直到饱和
2. 检查类别是否充分发展
3. 验证理论与数据的契合
4. 进行理论比较

**输出**：
- 饱和判断记录
- 理论验证报告
- 理论比较分析
- 最终理论报告

**质量检查**：
- [ ] 达到理论饱和
- [ ] 类别充分发展
- [ ] 理论与数据契合
- [ ] 与现有理论对话

## 理论抽样策略

### 抽样原则

根据理论发展的需要决定：
- 追随涌现的概念
- 寻找最大变异
- 填补概念空白
- 验证发展中的理论

### 抽样类型

| 类型 | 目的 |
|------|------|
| 开放抽样 | 初始探索，广泛收集 |
| 理论抽样 | 发展特定概念 |
| 区分抽样 | 明确概念边界 |
| 极端案例抽样 | 测试理论边界 |

## 适用场景

### 最佳适用

- 探索新现象或新领域
- 现有理论无法解释的现象
- 理论构建研究
- 理解社会过程
- 发展实质性理论

### 不太适用

- 验证已有假设
- 需要大样本统计推断
- 时间和资源极度受限
- 研究问题过于狭窄

- [ ] 与现有理论对话

## 常见误区

1. **预设理论框架**：带着已有假设收集数据，违背扎根精神
2. **过度文献回顾**：先入为主的文献影响开放性
3. **忽视负面案例**：只关注支持理论的数据
4. **编码过于表面**：停留在描述层面，缺乏概念化
5. **过早结束**：未达到理论饱和就停止
6. **忽视备忘录**：未及时记录分析思路

## 研究备忘录指南

### 备忘录类型

| 类型 | 内容 | 时机 |
|------|------|------|
| 编码备忘录 | 记录编码决策和理由 | 编码过程中 |
| 理论备忘录 | 记录理论思考和假设 | 任何时候 |
| 方法备忘录 | 记录方法决策 | 方法调整时 |
| 操作备忘录 | 记录操作安排 | 日常工作中 |

### 备忘录写作原则

- 及时记录，不要延迟
- 完整记录，不要简略
- 反思记录，不仅是描述
- 可追溯，标注时间和情境
