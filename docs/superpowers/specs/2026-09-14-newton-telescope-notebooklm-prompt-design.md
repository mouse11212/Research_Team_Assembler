## 1. 背景与目标

NLM-PPT-FRAMEWORK 已用「故事型（结草衔环）」「知识型（二十四节气）」两个案例验证了
概念→元素提取→风格决策→叙事设计→提示词整合→质量评估 的完整流程。本次在其上新增
**第三种概念类型适配：科技原理型**，主题为牛顿天文望远镜（反射式望远镜）原理，
面向 12-15 岁初中生做探究式引导科普。

用户已确认的需求决策：
1. 主题范围：原理为主 + 历史引入
2. 受众：初中生 12-15 岁（无公式、比喻类比优先、概念到"光反射/焦点/放大"层面）
3. 引导方式：探究式引导（问题驱动、猜想环节、类比生活经验）
4. 产出物：走完整框架流程（elements.json + style_profile.json + 提示词 + 案例报告）
5. 视觉风格：探险笔记手账风（框架风格库外定制，扩展为 ST-013）
6. 验证：只产出文件，不做 NoteBookLM 实机验证

## 3. 14 页探究主线（5 阶段）

```
阶段一 引发好奇（2页）
 P1 封面：牛顿天文望远镜·探险笔记
 P2 悬念导入：400年前，伽利略望远镜有个大毛病
    （引导问题：你看远处时为什么有时有彩边？）
阶段二 提出猜想（3页）
 P3 观察现象：折射望远镜的"彩虹边"（色差现象，生活类比：三棱镜/雨后彩虹）
 P4 大胆猜想：如果不用透镜"拐弯"光，用镜子"弹"光呢？（猜想区设计）
 P5 历史揭秘：1668年，25岁的牛顿造出了它（历史引入，手账时间轴）
阶段三 拆解原理（4页）
 P6 核心部件①：凹面镜——光的"聚光碗"（凹面镜聚光/焦点）
 P7 核心部件②：副镜——光的"接力棒"（45°平面镜反射）
 P8 核心部件③：目镜——放大镜看焦点（成像原理，光路图）
 P9 光路总览：一束星光的旅程（完整光路，逐步揭晓式呈现）
阶段四 验证理解（3页）
 P10 对比页：牛顿镜 vs 伽利略镜（无色差优势、短镜身）
 P11 生活关联：现代天文台/哈勃望远镜的"后代"（迁移应用）
 P12 小测验：3道选择题（探究式检验，答案下页揭晓）
阶段五 总结延伸（2页）
 P13 答案揭晓+总结：反射式望远镜的"三大法宝"（先揭晓 P12 测验答案，再总结凹面镜+副镜+目镜）
 P14 延伸探究：你可以动手试试（凹面镜聚光小实验/观星建议）
```

## 4. 探究式页面模板（每页四要素）

提示词中每个内容页必须包含：
1. **引导问题**（页首，制造认知冲突）
2. **猜想区**（"你觉得会怎样？"留白设计）
3. **揭晓内容**（本页知识）
4. **衔接钩子**（抛出下一页的悬念）

## 7. 科学性保障（提示词内置知识点锚定）

提示词逐页给出准确科学事实，防止 NoteBookLM 自由发挥出错：
- 凹面镜（抛物面）把平行光反射汇聚到焦点
- 牛顿第一台反射镜：主镜口径 3.3 cm、焦距约 15 cm（1668 年）
- 副镜为 45° 平面镜，把焦点处光线反射到镜筒侧壁
- 目镜是凸透镜，放大焦点处的像
- 折射镜色差：不同色光折射角度不同，透镜边缘出现彩边
- 牛顿镜优点：无色差 + 镜身短（反射光路"折叠"）；缺点：副镜遮挡少量光、主镜需镀膜维护

## 9. 风险与错误处理

| 风险 | 处理 |
|------|------|
| R1 NoteBookLM 无法生成互动结构 | 提示词内置结构降级说明（降级为设问+讲解式，保留引导问题与衔接钩子） |
| R2 科学知识错误（LLM 幻觉） | 逐页锚定准确事实 + 质量检查清单强制核对 |
| R3 手账风过度装饰干扰阅读 | 提示词限定装饰密度（每页≤3处贴纸，正文区干净） |
| R4 元素提取不适配科技原理型 | A003 用"知识框架提取法"适配：提取维度=光路组成/发明动因/对比优势/历史节点（24 节气先例已验证可迁移） |
